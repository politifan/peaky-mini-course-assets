# Peaky Minds mini-course illustrations

Original illustrations for nine free mini-courses on Stepik.

Terminal PNGs render transcripts of genuine command sessions on Debian 13, recorded on 8 October 2026. Text transcripts accompany each subject. Error output is preserved; identifiers and timing naturally vary on another machine.

GitHub and HTTP browser screenshots show actual public pages. Orange outlines and an explanatory caption were added to the live DOM before capture; the page content was not replaced. GitHub remains the owner of its interface and trademarks. Public views may omit buttons that require signing in.

The SVG mountain illustration is original. No credentials, private learner data or author grading answers are included in this repository.
